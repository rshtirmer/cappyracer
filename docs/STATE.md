- **Stutter fix (user-reported "cars shake / stutter unlike the AI").** TWO causes: (1) traffic InstancedMeshes are in `worldGroup` so they got the PS2 vertex-snap wobble (`applyVertexSnapToScene`) that the karts (in `scene`) never get → now flagged `userData.noPS2`; (2) **the real culprit** — `Track.pointAt(progress)` does `Math.round(progress*n)` and **snaps to one of 420 discrete samples**, so a slow car sat still for several frames then teleported ~0.8 units to the next sample (karts integrate position continuously, hence smooth).
